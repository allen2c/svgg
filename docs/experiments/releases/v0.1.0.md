# SKILL.md 0.1.0

Released 2026-11-06. First version; evaluated in iteration 1
([`../daily/2026-11-06.md`](../daily/2026-11-06.md)).

## What it contains

Five modes (`create`, `reference`, `vectorize`, `edit`, `animate`); a
written brief and plan before drawing; geometry rules (primitives first,
few nodes, rounded coordinates, named groups); a forbidden list; an
eight-item check with optional rendering; a delivery format; one example.

## Evaluation

nothing forbidden. `edit-weather-card-to-night` and `animate-weather-card`
were ties (no visible difference between models) and are not scored.

## Known weaknesses (candidates for 0.2.0)

- Defaults fit icons badly (8% margin) and badges or tiles badly
  (transparent background, no text).
- Edit mode forbids the side effects a change needs (label contrast).
- Scene vectorization: weak models fall back to repeated patterns or dense
  paths; the color budget is ambiguous.
- No way to verify motion; pivot rule fragile.
- Tasks `edit` and `animate` v1 are too easy to separate models.
