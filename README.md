# svgg

An agent skill for drawing clean, editable SVG directly with an LLM:
create, use references, vectorize, edit, and animate.

The skill is the single file [`SKILL.md`](SKILL.md). Point any agent at it
(raw URL or local path) and ask for an SVG; it needs no install step and no
tools beyond writing text, and uses a renderer when one is available.

Development notes, test tasks, and results: [`docs/experiments/`](docs/experiments/README.md).
